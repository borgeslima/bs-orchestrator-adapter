Sobre o projeto

orch-poc é uma prova de conceito de orquestração de processos de negócio (cap-giro) construída com foco em arquitetura limpa, processamento assíncrono, idempotência e resiliência.

Objetivo

Demonstrar um motor de orquestração baseado em etapas que seja tolerante a falhas e duplicidades. O estado vive no MongoDB (fonte da verdade) e o avanço entre etapas é coordenado por mensageria (Azure Service Bus), permitindo escala horizontal do consumo.

Estrutura de pacotes

Organização por Arquitetura Hexagonal sob com.bradesco.orch:

com.bradesco.orch
├── domain
│   ├── entity        # Orquestracao, Etapa, Controle, RespostaEtapa, RegistroInteracao, TipoInteracao...
│   └── port
│       ├── in        # UseCases + comandos + resultados
│       └── out       # OrquestracaoRepository, MensagemPublisher, EtapaProcessor...
├── application       # Services (implementam os UseCases)
├── adapter
│   ├── in
│   │   ├── rest       # CapGiroController + DTOs
│   │   └── messaging  # EtapaServiceBusListener
│   └── out
│       ├── persistence  # Mongo repository, documents, mapper
│       ├── messaging    # ServiceBusMensagemPublisher
│       ├── processor    # Processors de etapa + registry + client mock
│       └── policy       # InteracaoPolicy (interação humana ou de máquina)
└── config            # Mongo, ServiceBus, RestClient, OpenApi, Jackson

Configuração

Principais variáveis de ambiente (com defaults em application.properties):

VariávelDescrição
SERVER_PORTPorta HTTP (padrão 8081).
MONGODB_URIConexão MongoDB (fonte da verdade).
SERVICEBUS_CONNECTION_STRINGConexão do Azure Service Bus.
SERVICEBUS_FILANome da fila (padrão orchestration).
ETAPAS_ENDPOINTBase URL do mock das etapas.
ETAPAS_INTERACAO_HUMANANomes canônicos de etapas (separados por vírgula) que exigem interação/aprovação antes de avançar. Vazio = fluxo automático.
SWAGGER_UI_PATH / API_DOCS_PATHPaths do Swagger / OpenAPI.
Segurança. O default de MONGODB_URI traz credenciais de desenvolvimento embutidas. Elas devem ser rotacionadas após a POC e substituídas por variável de ambiente em qualquer ambiente compartilhado.

Como executar

Local (Maven)

# Windows PowerShell
.\mvnw.cmd spring-boot:run

Infra local (Docker)

O diretório docker/ traz um docker-compose.yaml para subir as dependências locais (ex.: emulador de Service Bus).

docker compose -f docker/docker-compose.yaml up -d

Versionamento

Esta documentação segue Versionamento Semântico (MAJOR.MINOR.PATCH) e acompanha a evolução da API.

VersãoDataMudanças
v1.1.0 2026-09-15 Endpoint de aprovação (POST /cap-giro/{id}/etapas/{etapa}/aprovar) e interação genérica: InteracaoPolicy e RegistroInteracao passam a registrar apenas tipo (HUMANA/MAQUINA) e aprovadoEm.
v1.0.0 2026-09-11 Versão inicial. Fluxo de orquestração cap-giro, 3 endpoints REST (POST /cap-giro, GET /cap-giro/{id}, GET /cap-giro/{id}/etapas) e documentação do processamento assíncrono.
Convenção. Incremente MAJOR em mudanças incompatíveis de contrato, MINOR em novas funcionalidades retrocompatíveis e PATCH em correções e ajustes de documentação.
