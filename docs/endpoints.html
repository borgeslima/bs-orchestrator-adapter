Endpoints REST

Todos os endpoints são expostos por CapGiroController sob o prefixo /cap-giro. As respostas usam JSON.

Base & convenções

Base path/cap-giro
Porta padrão8081 (variável SERVER_PORT)
Content-Typeapplication/json
CorrelaçãoOpcional via correlationId no corpo de início; gerado automaticamente se ausente.

Iniciar orquestração

POST /cap-giro

Cria e dispara uma orquestração de cap-giro de forma assíncrona. Não aguarda a conclusão das etapas.

Request body opcional

{
  "correlationId": "a1b2c3d4-..."   // opcional; se ausente, gera um UUID
}

O corpo inteiro é opcional. Enviar POST /cap-giro sem body é válido.

Respostas

CódigoDescriçãoBody
202 Accepted Orquestração aceita para processamento. IniciarOrquestracaoResponse 
{
  "orquestracaoId": "665f1c2a9b4e2a0012a3b4c5"
}

Exemplo

curl -i -X POST http://localhost:8081/cap-giro \
  -H "Content-Type: application/json" \
  -d '{ "correlationId": "pedido-42" }'

Consultar orquestração completa

GET /cap-giro/{orquestracaoId}

Retorna a orquestração completa: dados gerais e a lista de etapas com seus estados.

Parâmetros de path

NomeTipoDescrição
orquestracaoIdstringId retornado no início da orquestração.

404 Not FoundOrquestração não existe.—

Consultar apenas as etapas

GET /cap-giro/{orquestracaoId}/etapas

Retorna somente a lista de etapas (EtapaResponseView) da orquestração.

Respostas

CódigoDescriçãoBody
200 OKEtapas encontradas.List<EtapaResponseView>
404 Not FoundOrquestração não existe.—

Modelos de dados

OrquestracaoResponse

CampoTipoDescrição
orquestracaoIdstringId da orquestração.
namestringNome da orquestração.
orderintOrdem/sequência.
statusstringPENDENTE, EM_EXECUCAO, CONCLUIDA, ERRO.
dataCriacaoInstantData de criação.
dataAtualizacaoInstantÚltima atualização.
etapasEtapaResponseView[]Etapas da orquestração.

EtapaResponseView

CampoTipoDescrição
namestringNome canônico da etapa.
